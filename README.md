## 1. Project Overview

Ishita-verse is a personal portfolio website developed to showcase my academic projects, technical skills, professional experiences, achievements and personal interests.

The website reflects my journey as a Data Science student with a strong interest in cricket, sports analytics, research and technology.

It was designed to be responsive, interactive and visually engaging while presenting information in a structured and accessible manner.

## 3. Interactive Features

The website incorporates several custom interactive components:

- **The Ishita Route:** A Vespa-themed scroll tracker indicating progress through the website.
- **The Ishita Scoreboard:** Animated statistics representing personal milestones.
- **Ishita FM:** An interactive vinyl animation with play and pause controls.
- **The Detour Diaries:** Flip-style postcards representing personal interests and experiences.
- **Project Collector's Edition:** Custom hover effects and collectible-style project cards.
- **The Six-Hit Challenge:** A hidden three-ball cricket mini-game.
- **Responsive Navigation:** Mobile-friendly navigation and layouts.

These elements were incorporated to make the portfolio more engaging and to reflect my personality and interests.

## 5. How to Run the Website Locally

1. Clone the repository:

   `git clone https://github.com/IshitaSahni/personal-portfolio.git`

2. Open the downloaded `personal-portfolio` folder.

3. Open `index.html` in a web browser.

4. Navigate through the website and explore its interactive features.

No additional software packages or dependencies are required to run the website.
