02 / STOCHASTIC PROCESSES
PROJECT 02

Music Generation Using Markov Chains

Developed an interactive music generation application using Markov Chains, exploring how stochastic processes and probability-based models can be applied to musical composition.

The project uses a hierarchical Markov Chain architecture to model transitions between musical elements, including melody, rhythm and chord progressions. By incorporating transition probabilities and temperature scaling, the system generates multi-track MIDI compositions with varying levels of musical structure and randomness across 11 genres.

Built using Python and Streamlit, the application demonstrates how mathematical modelling can be translated into a creative, interactive system, combining stochastic processes, data-driven generation and music.

Python Streamlit Markov Chains Stochastic Processes MIDI

04 / CONSERVATION AI
PROJECT 04

AI-Based Bird Recognition & Conservation

Balipara Foundation × EPICS

Developed an AI-based bird recognition pipeline as part of a collaborative conservation project with the Balipara Foundation through EPICS, focusing on automated species identification from camera-trap imagery in Northeast India.

The system uses YOLOv8 to detect and isolate birds from cluttered forest backgrounds, followed by ResNet-50 feature extraction and cosine similarity matching against a reference database of 34 regional bird species. The pipeline also incorporates image preprocessing and standardisation to improve the reliability of classification.

An interactive Streamlit dashboard supports species-level analysis, confidence-based filtering and visual verification of predictions, enabling a human-in-the-loop approach to biodiversity monitoring. The project demonstrates how computer vision can help streamline ecological data processing while supporting more efficient wildlife research.

Python YOLOv8 ResNet-50 PyTorch Computer Vision Cosine Similarity Streamlit

WORK IN PROGRESS

Adversarial Multi-Agent System for In-Game Cricket Analytics

Currently developing an adversarial multi-agent system designed to support data-driven decision-making in cricket through natural-language querying, statistical analysis and tactical evaluation.

The proposed system uses a LangGraph-based multi-agent architecture to translate cricket-related questions into database queries, analyse match situations and evaluate potential strategies. A key component of the architecture is an adversarial Critic Agent, designed to challenge tactical recommendations and assess alternative decisions before presenting insights. This approach aims to move beyond conventional statistical dashboards towards more context-aware and strategically informed cricket analytics.

The initial implementation supports basic query functionality, with further development focused on integrating specialised agents, statistical simulations and adversarial tactical evaluation.

Python LangGraph Multi-Agent Systems NL-to-SQL Statistical Modelling Cricket Analytics
